# Data sources

## INE — Nomenclátor: Población por unidad poblacional

| Field | Value |
| --- | --- |
| Operation | INE operation 30261 |
| Reference date | 2025-01-01 |
| Published | 2026-01-28 |
| Download (national ZIP) | POST `https://www.ine.es/nomen2/Descarga` with `anioNacional=2025` |
| Results page | https://www.ine.es/dyngs/INEbase/operacion.htm?c=Estadistica_C&cid=1254736177010&menu=resultados&idp=1254735572981 |
| Register design | https://www.ine.es/nomen_files/DisenioRegistro.xls |
| Methodology | https://www.ine.es/nomenclator/metodologia.htm |
| License | https://www.ine.es/aviso_legal |

**Files used in pipeline (inside national ZIP):**

- `nomdef2025.xlsx` — structured columns (preferred for parsing)
- `Nomdef2025_sex.txt` — fixed-width text (alternative; population fields can overflow name padding for large municipalities)

**Population methodology note:** From reference date 2024-01-01 onward, INE uses **Censo Anual de Población** (not only municipal padron revisions). See INE Nomenclátor front matter.

**Local copy metadata:** `data/raw/ine/source-metadata.json` (generated by download script).

## IGN / CNIG — Nomenclátor Geográfico de Municipios y Entidades de Población (NGMEP)

| Field | Value |
| --- | --- |
| Portal | https://centrodedescargas.cnig.es/ |
| Purpose | Coordinates, geometries, capital flags, normalized names |
| Join key | 11-digit INE code (`codine` / `CODIGOINE`) |
| Documentation | https://centrodedescargas.cnig.es/CentroDescargas/documentos/Memoria_NGMEP.pdf |

**Status:** Not yet imported in automated pipeline. Phase 1 exports INE-only canonical places; coordinate merge is a documented next step once NGMEP shapefile/GeoPackage is downloaded to `data/raw/ign/` (gitignored).
